# طراحی بصری و تجربهٔ کاربری (مرجع اجباری فرانت) — §۴۱ PRD

## شخصیت
آرام، دانشگاهی، دقیق و کم‌تزئین. گرم کاغذی. ممنوع: داشبورد مالی، کارت تزئینی بی‌کارکرد، رنگ شدید مذهبی/تبلیغاتی، گرادیان‌های نمایشی.

## tokenهای رنگ (Tailwind vars — دقیقاً همین hexها)
روشن / تیره: canvas `#F7F5EF`/`#111A1D`؛ surface `#FFFFFF`/`#18252A`؛ reader `#FFFCF5`/`#152127`؛ text `#182A32`/`#E7EDEB`؛ muted `#55646B`/`#A8B8B3`؛ primary `#17665B`/`#8ED3BD`؛ link `#145C9E`/`#8AC7F8`؛ border `#D6DAD7`/`#364950`؛ control-border `#75807D`/`#697F77`؛ match-bg `#FFE8A3`/`#59481F`.
- متن روی primary روشن = سفید؛ روی primary تیره‌حالت‌دار = متن تیره. semantic ayah سبز ملایم + نشان نقش؛ sanad: muted در زمینهٔ خنثی؛ شرح: نشانه + کادر ملایم. رنگ تنها حامل معنا نیست (نشانهٔ متنی همیشه همراه).
- حالت تیره با next-themes (class). همهٔ صفحات روی canvas؛ متن مطالعه روی reader.

## تایپوگرافی
- UI: Vazirmatn (از @fontsource/vazirmatn — محلی، ممنوع CDN)؛ متن عربی مطالعه: Amiri (@fontsource/amiri)؛ UI معمول 14–16px.
- متن مطالعه: عربی پیش‌فرض 22px، فارسی 20px؛ قابل تنظیم 16–32px؛ line-height اولیه 1.9؛ عرض مؤثر حداکثر ~760px وسط.
- scale فاصله 4/8/12/16/24/32؛ radius 8–12px؛ سایهٔ خیلی کم. اعداد فارسی در نمایش، مقدار اصلی در کپی حفظ شود. شناسه/URL با `dir="ltr"` و bidi-isolation.
- html `dir="rtl" lang="fa"`؛ قطعات عربی `lang="ar" dir="rtl"`.

## breakpointهای کتاب‌خوان (اجباری)
- ≥1440px: فهرست/نتایج در **راست**، متن وسط، زمینه در **چپ** (سه ستون، react-resizable-panels).
- 1024–1439: دو ستون؛ پنل سوم با تقاضا (Sheet).
- 768–1023: متن اصلی؛ فهرست drawer، زمینه sheet.
- <768: تک‌ستونی، header کم‌ارتفاع، ناوبری پایین (bottom tabs)، هیچ عملیات hover-ضروری. هدف لمسی ≥44px.

## واژگان رابط (دقیقاً همین‌ها؛ شناسهٔ فنی در UI ممنوع)
«جست‌وجو در منابع»، «نام کتاب»، «کتابخانه»، «موضوعات»، «پژوهش‌های من»، «ادامهٔ مطالعه»، «متن روایت»، «سند روایت»، «بیان مؤلف»، «مشاهدهٔ اصل»، «انتشار اصلاحات».
تطبیق‌ها: «عبارت دقیق»، «عبارت نرمال‌شده»، «جست‌وجوی واژه‌ها»، «تطبیق تقریبی». شمارش ناقص: «تطبیق‌های تأییدشده تا این لحظه». نبود پوشش: «این منبع نشانه‌گذاری تخصصی ندارد» / «متن جست‌وجوپذیر ندارد».
خطا: چه اتفاقی افتاد + اقدام بعدی (فارسی)؛ هرگز exception انگلیسی/stack/JSON خام.

## صفحات و رفتار اجباری
1. **ورود**: فرم ساده، خطا فارسی، پس از ورود بازگشت به hash مقصد.
2. **خانهٔ جست‌وجومحور**: جست‌وجوی اصلی با انتخاب «متن منابع / نام کتاب»؛ زیر آن ۳ ورودی کوتاه (کتابخانه، موضوعات، پژوهش‌های من)؛ «ادامهٔ مطالعه» و منابع اخیر compact؛ پرونده‌های اخیر. بدون آمار تزئینی.
3. **کتابخانه**: جدول/فهرست آثار (عنوان، مؤلف، ناشر، زبان، تعداد اسناد) + جست‌وجوی سریع + فیلترها؛ badge امکانات (روایت/آیه/پاورقی/موضوع/رسانه)؛ «متن جست‌وجوپذیر ندارد» برای کتاب تصویری.
4. **صفحهٔ اثر**: جلدها/مدخل‌ها جدا؛ مسیر «اثر ← جلد ← صفحه»؛ پوشش صریح.
5. **کتاب‌خوان (میز مطالعه)**: نوار بالا (عنوان اثر/جلد/صفحه + پرش به صفحهٔ چاپی + جست‌وجو در همین کتاب/جلد + وضعیت ذخیره)؛ فهرست درختی؛ متن با بلوک‌های ساخت‌یافته؛ پاورقی در پنل/کارت با بازگشت فوکوس؛ انتخاب متن → دکمهٔ فیش (نقل‌قول اصل/بدنهٔ روایت/همراه سند)؛ highlight نتیجهٔ جست‌وجو قابل پاک‌کردن؛ نشانک؛ تنظیمات قلم/اندازه/فاصله/حالت تیره (بدون پرش موضع)؛ حالت صفحه‌محور و پیوسته؛ sanad قابل جمع (با نشان تعداد؛ حذفش سند = سخن معصوم نیست — HAD-10)؛ سند متمایز muted؛ ayah با نشان + پنل؛ sharh با کادر ملایم؛ ارجاع حل‌نشده → پیام + نشانی اصلی.
6. **نتایج جست‌وجو**: query + chips فیلتر قابل حذف + دکمهٔ پاک‌کردن همه؛ دو سطح «مواضع» و «کتاب‌های دارای تطبیق تأییدشده»؛ هر کارت: عنوان/نسخه، جلد/صفحه، نوع تطبیق، شاهد با highlight، «بازکردن در متن» (اقدام اصلی) و «افزودن به فیش» (secondary)؛ شمارش «تا این لحظه» + دکمهٔ «ادامهٔ بررسی»؛ سه وضعیت خالی متفاوت (بدون نتیجه / نمایه آماده نیست / خطای موتور).
7. **پژوهش‌های من**: پرونده‌ها، فیش‌ها با وضعیت ذخیره (در حال ذخیره/ذخیره شد/ناموفق+تلاش دوباره)، سطل بازیافت، خروجی.
8. **مقایسه**: دو ستون مستقل در دسکتاپ؛ موبایل: زبانهٔ سریع.
9. **مدیریت**: داشبورد موجودی/وضعیت پردازش/release فعال/خطاها/فضای دیسک؛ overlay با چرخهٔ پیش‌نویس←اعتبارسنجی←پیش‌نمایش←انتشار (MFA)←rollback؛ کاربران و دعوت‌ها؛ jobs.
10. **تنظیمات**: خواندن، ظاهر، نشست‌های فعال، خروج.

## حالت‌ها (همهٔ قابلیت‌ها)
هر قابلیت loading (skeleton) + empty (فارسی + پیشنهاد) + error (پیام + تلاش دوباره) + «بدون پوشش» دارد. هیچ باقی‌ماندن spinner ابدی. autosave فیش: «در حال ذخیره…/ذخیره شد/ذخیرهٔ ناموفق» + پیش‌نویس محلی موقت تا بستن امن.
